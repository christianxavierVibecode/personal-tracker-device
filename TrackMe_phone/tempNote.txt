script untuk menyatukan file video, audio dan thumbnail dengan ffmpeg :
Video + Audio + thumbnail:
for video in *.mp4; do basename="${video%.mp4}"; audio="${basename}.mp3"; thumb="${basename}.png"; output="HASIL_${video}"; if [[ -f "$audio" && -f "$thumb" ]]; then ffmpeg -i "$video" -i "$audio" -i "$thumb" -map 0:v:0 -map 1:a:0 -map 2:v:0 -c:v copy -c:a copy -c:v:1 png -disposition:v:1 attached_pic -map_metadata 0 "$output" -y; elif [[ -f "$audio" ]]; then ffmpeg -i "$video" -i "$audio" -map 0:v:0 -map 1:a:0 -c:v copy -c:a copy -map_metadata 0 "$output" -y; fi; done

Video + Audio saja :
for v in *.mp4; do b="${v%.mp4}"; a="$b.mp3"; t="$b.png"; out="HASIL_$v"; if [[ -f "$a" && -f "$t" ]]; then ffmpeg -i "$v" -i "$a" -i "$t" -map 0:v:0 -map 1:a:0 -map 2:v:0 -c:v copy -c:a copy -c:v:1 png -disposition:v:1 attached_pic -map_metadata 0 "$out" -y; elif [[ -f "$a" ]]; then ffmpeg -i "$v" -i "$a" -map 0:v:0 -map 1:a:0 -c:v copy -c:a copy -map_metadata 0 "$out" -y; fi; done

Menghapus semua file yang berakhiran .webm di dalam folder :
rm *.webm

Menghapus semua file yang selain di awali dengan karakter "HASIL_" di dalam folder :
find . -maxdepth 1 -type f ! -name "HASIL_*" -delete

Merename semua file dengan ekstensi webm menjadi mp4 :
for f in *.webm; do mv "$f" "${f%.webm}.mp4"; done

Melihat jumlah file mp4 di direktori saat ini :
ls -1 *.mp4 | wc -l

yt-dlp --update-to nightly
