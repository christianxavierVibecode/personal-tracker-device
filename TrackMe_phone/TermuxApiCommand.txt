CATATAN PERINTAH TERMUX:API
==============================

#1. INFORMASI AUDIO & MEDIA
termux-audio-info

#2. MEMUTAR / MENGONTROL AUDIO
termux-media-player

	# Memutar file audio bernama file.mp3
	termux-media-player play file.mp3

	# Mempause file audio yang di putar
	termux-media-player pause

	# Menghentikan file audio yang di putar
	termux-media-player stop

#3. MEREKAM SUARA DARI MICROPHONE
termux-microphone-record

	# Memulai rekaman dan simpan di file rekam.wav
	termux-microphone-record -f rekam.wav

	# Menghentikan rekaman dan menyimpannya di file rekam.wav
	termux-microphone-record -q


#4. INFORMASI KAMERA
termux-camera-info

#5. MENGAMBIL FOTO (DEPAN / BELAKANG)
termux-camera-photo

	# Mengambil foto dari KAMERA LUAR + simpan sebagai foto.jpg
	termux-camera-photo foto.jpg

	# Mengambil foto dari KAMERA DALAM + simpan sebagai selfie.jpg
	termux-camera-photo -c 1 selfie.jpg

#6. MENAMPILKAN NOTIFIKASI ANDROID
termux-notification

#7. POPUP TOAST ANDROID
termux-toast

#8. DIALOG INTERAKTIF (INPUT USER)
termux-dialog

#9. GET ISI CLIPBOARD
termux-clipboard-get

#10. SET ISI CLIPBOARD
termux-clipboard-set

#11. MENGAMBIL LOKASI GPS
termux-location

	# Ambil data lokasi dari gps (lebih akurat)
	termux-location -p gps

	# Ambil data lokasi dari AP 
	termux-location -p network
