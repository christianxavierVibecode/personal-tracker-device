INSTALASI SSH
sudo apt update && sudo apt upgrade -y
sudo apt install openssh-server openssh-client -y
ssh -V
sudo service ssh status
	jika belum running, jalankan : sudo service ssh start
	jika ingin di-restart, jalankan : sudo service ssh restart

sudo adduser sshuser
sudo usermod -aG sudo sshuser

Perintah untuk melihat apakah service ssh itu berjalan di termux :
	Perintah 1	=> pgrep sshd (muncul angka (PID) berarti ssh sedang aktif)
	Perintah 2 	=> ps aux | grep sshd (/usr/bin/sshd)
	Perintah 3 	=> ss -nlt (biasanya port 8022)
	Perintah 4 	=> ssh localhost -p 8022 (testing sendiri)
Cek ssh di laptop	=> Get-Service sshd
Run ssh di laptop	=> Start-Service sshd
Matikan ssh di termux	=> Stop-Service sshd
Restart ssh di laptop	=> Restart-Service sshd
Disable ssh auto start	=> Set-Service sshd -StartupType Disabled
Enable ssh auto start	=> Set-Service sshd -StartupType Automatic

Cek ssh di termux	=> ps aux | grep sshd
Run ssh di termux	=> sshd
Matikan ssh di termux	=> pkill sshd
Restart ssh di termux	=> pkill sshd && sshd
